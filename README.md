# Tuler-s-Dynamic-Dungeon
O intuito desse projeto é criar uma página na web que sirva como um ficha de rpg personalizável e dinâmica, facilitando uma mesa de rpg online.

--funções--
Tracker de HP, MP, sanidade e outros atributos dos personagens, rolador de dado automático com cálculo baseado em atributos.

Notepad imbutido de anotações para que os players não se esqueçam de informações importantes.

Aba para adicionar informações sobre monstros novos encontrados.
